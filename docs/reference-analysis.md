# 参考视频分析

参考片段标题为「立体书：约束越多，作品越能脱颖而出」。分析依据已下载的参考视频及关键帧，视频参数为 1920 × 1080、30 fps、1146 帧、38.2 秒。

下列时间由关键帧和每 0.1 秒抽样观察整理，切换端点约有 ±0.1 秒误差；字幕时段包含其短暂淡入淡出。复刻以这些时间作为动画同步依据。

## 构图与层次

画面为 16:9 横版，主体始终置于木桌上。前半段 OMNI 纸盒和书本分别占据中心，后半段通过缩放与平移形成左右比较，再回到居中的立体书。主要动作由纸片、书页与道具的翻折、立起和位移完成，转场多采用同一桌面内的物体变形与镜头重构。

立体书有清楚的前后层次：后页是月亮、山峦、房屋和灯塔；中层是四格胶片；前层是火车、火箭、电脑、无人机、纸偶和留声机；最前沿是五块分类纸牌。接触阴影和向右延伸的投影让纸片具有厚度。背景木桌纹理较暗，画面边缘有暗角，视觉焦点落在米色纸面与彩色纸艺上。

五块分类牌从左到右为「世界观·故事」「时间跨度」「时代背景」「画面风格」「节奏·声音」，对应绿色、土黄、红色、蓝色、紫色。该色序同时贯穿对话气泡、书页标签与其他小元素。

## 颜色、字体与材质

整体色调是低亮度的暖棕木色与米白纸色，深青书皮和海景形成主要色块，少量暖红、金黄、绿色、蓝色和紫色用于标签与道具。可参考的近似色值为木桌 `#4f3013`、纸面 `#e9ddbd`、深青 `#12383d`、暖红 `#ba382a`、金黄 `#d49b30`。这些是用于复刻的视觉近似，原片颜色受阴影、暗角和光照影响。

字幕是黑色粗宋体或同类中文衬线体，横竖笔画对比明显；仅凭画面无法确认原字体文件。字幕位于底部中央，中心约为 `(960, 982)`，字高约 48–52 像素，米白撕纸条高度约 90–100 像素，宽度随文字长度变化。纸条边缘不规则，单行排版，保持与桌面和书本之间的分离。

复刻使用 `NotoSerifCJKsc-Bold.otf` 呈现中文衬线效果，字体随附 OFL 许可。木纹和纸粒通过工程中的 SVG 纹理叠加，纸张边缘、投影和开合透视由 SVG 与 CSS 构建。

## 动作与转场

前 9 秒以纸张进出、对话气泡依次出现和叠书为主，动作密度较高。9–25 秒进入立体书逐层展开阶段，每个叙述维度对应一个新增的视觉层或道具，主要动作通常在约半秒到一秒内完成。26 秒后通过镜头拉远、左右比较、纸张散落和书本重新展开完成观点收束。

字幕以短暂淡入淡出切句，大部分切换之间保留约 0.1–0.3 秒的空隙。参考音轨仅用于本机分析，不随公开工程发布；公开版使用 `scripts/generate-audio.py` 自行合成的纸张、机械音效与和声，字幕和展开动作仍按参考旁白的时点对齐。字幕停留时间随语句长度变化，而灯塔光束等次要动作持续发生，避免静止展示阶段完全失去运动。

## 复刻边界

程序化复刻重建主要元素、布局与叙述节奏。纸质模型的造型、真实纸张纤维、三维光照、景深和精细透视以可维护的 SVG/CSS 方法近似，结果并非像素级一致。原参考视频画面不作为视频播放层使用。
